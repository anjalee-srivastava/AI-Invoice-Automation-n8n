🧾 AI-Powered Invoice Automation using n8n, OpenAI & Telegram

🚀 Project Overview

An AI-powered invoice automation system developed using n8n, OpenAI, and Telegram.

This project demonstrates how multiple AI agents can work together to process customer orders, interpret natural language, prepare billing information, generate professional invoice images, and deliver them through Telegram.

The workflow supports both text and voice-based invoice requests, including Hindi, English, and Hinglish.

💡 Business Problem

Traditional invoice creation often requires manually entering customer information, product details, quantities, prices, discounts, and taxes.

This project explores how AI-driven automation can simplify these repetitive tasks through conversational interactions.

🎯 Project Objective

Build an intelligent invoice automation workflow that:

* Accepts invoice requests through Telegram.
* Supports text and voice messages.
* Extracts customer and product information.
* Processes billing information using AI agents.
* Generates professional invoice images.
* Automatically sends generated invoices through Telegram.

⸻

✨ Key Features

📩 1. Telegram Bot Integration

Users can initiate invoice requests by sending messages directly to a Telegram bot.

🎙️ 2. AI-Powered Voice Transcription

Voice messages are processed using OpenAI speech-to-text functionality.

This enables users to request invoices without manually typing product information.

🧠 3. Reader AI Agent

The Reader Agent interprets customer requests and extracts:

* Customer name and email
* Product names
* Quantities
* Unit prices, when provided
* Discount instructions
* Delivery and payment preferences

The agent is instructed to recognize Hindi, English, and Hinglish requests and identify missing or ambiguous product details.

💼 4. Billing AI Agent

The Billing Agent receives structured information from the Reader Agent.

Its responsibilities include:

* Matching products against a predefined price list.
* Applying applicable discounts.
* Preparing invoice details.
* Calculating GST according to the configured billing rules.
* Producing billing information for invoice generation.

Note: Billing calculations are currently directed through AI instructions. Dedicated calculation and validation tools are planned enhancements.

🎨 5. AI Invoice Image Generation

OpenAI image generation transforms billing information into a professionally formatted invoice image.

The invoice design includes:

* Business branding
* Customer details
* Invoice number and dates
* Product descriptions
* Quantities and prices
* Discounts
* GST
* Grand total
* Payment information

📤 6. Automated Telegram Delivery

The generated invoice image is automatically returned to the Telegram conversation.

🔧 Installation and Setup

Prerequisites

* An n8n instance
* A Telegram bot created using BotFather
* Access to the required OpenAI models
* Telegram and OpenAI credentials configured in n8n

Setup Instructions

Step 1: Download the workflow JSON file from this repository.

Step 2: Open your n8n instance.

Step 3: Create a new workflow.

Step 4: Import the downloaded JSON file.

Step 5: Configure the required Telegram and OpenAI credentials.

Step 6: Review the Reader Agent and Billing Agent instructions.

Step 7: Replace the demonstration shop information and product price list with your own test data.

Step 8: Test the workflow using a Telegram text message.

Step 9: Test the voice-message transcription path.

Step 10: Verify the invoice output, including product details, calculations, and delivery.

Important: This is a demonstration workflow. Generated invoices must be reviewed before being used for real transactions.

🧪 Example Use Case

A shop owner sends the following message through Telegram:

Create an invoice for a customer purchasing 10 LED bulbs, one refrigerator, and one air conditioner. Apply a 15% discount.

The automation is designed to:

1. Receive the message.
2. Extract the customer and product details.
3. Identify missing specifications when necessary.
4. Prepare structured billing information.
5. Apply configured pricing and discount rules.
6. Generate an invoice image.
7. Send the generated image through Telegram.
